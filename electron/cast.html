On stage / known actors

Every body currently standing, plus every actor the file names even when it is not on stage right now. Each control writes straight to cast.json — ASSIGN here never SWITCHES the resident's own model the way the tray menu does.

Who may speak

Origins the room has actually seen, whether or not the file grants them anything yet. An origin nobody configured is audible by default unless it is a relay channel (those start silent) — this list is how a legitimately new agent stops being mysteriously mute in one click.

Stage defaults

Unset fields fall through to the built-in (shown as placeholder). The ✕ button clears a field back to unset, distinct from typing a value that happens to match the default.

Voice defaults

The endpoint host/port/path is what the desk dials for AitherVoice — today it is hardcoded to 127.0.0.1:8084 in code; here it is a setting.

Desk behaviour

Which backend the Command window's agent runs on, what it is told, and whether the desk looks at images you drop on it. Each was an environment variable or a constant in code; the small print under a field says where its current value comes from.

Sync to your other machines

Off until you turn it on. Point it at a file in a folder you already sync, or at a profile URL. This section itself never leaves this machine — it holds local paths.
